# Love at First Paws 🐶🐱

A pet adoption website where users can browse available pets, give away a pet, find dog/cat care tips, and contact the organization. The project is built using Node.js, Express, and EJS templating, with client-side interactivity using JavaScript.

## 🚀 Features

- 🐾 Browse available cats and dogs for adoption
- 📤 Submit a pet for adoption
- 🔍 Filter/search pets by type, breed, age, and gender
- 📚 View dog and cat care information
- 📬 Contact form for inquiries
- 🧩 Modular templating with EJS partials (header/footer)
- 🌐 Static file serving with Express
- 🎨 Custom CSS styling
- ⚙️ Node.js server with route handling

## 🛠️ Technologies Used

- **Node.js**
- **Express**
- **EJS**
- **HTML5/CSS3**
- **Vanilla JavaScript**
- **Font Awesome**

### 🔒 Privacy Disclaimer

This website respects your privacy. No personal information is stored or shared. Pet listings are user-generated and accuracy is not guaranteed.
