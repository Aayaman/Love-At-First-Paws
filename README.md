# Love at First Paws 🐶🐱

Welcome to **Love at First Paws**, a pet adoption platform designed for users to either **adopt a pet** or **give away one to a loving home**. Originally built using Express.js, this project has been transformed into a **static website using only HTML, CSS, and JavaScript** to enable deployment on **GitHub Pages**.

🔗 **Live Website:**  
👉 [https://aayaman.github.io/Love-At-First-Paws/](https://aayaman.github.io/Love-At-First-Paws/)


## Project Structure 
### 🚀 Features

- 🐾 Browse available cats and dogs for adoption
- 📤 Submit a pet for adoption
- 🔍 Filter/search pets by type, breed, age, and gender
- 📚 View dog and cat care information
- 📬 Contact form for inquiries
- 🧩 Modular templating with EJS partials (header/footer)
- 🌐 Static file serving with Express
- 🎨 Custom CSS styling
- ⚙️ Node.js server with route handling

### 🛠️ Technologies Used

- **HTML5/CSS3**
- **Vanilla JavaScript**
- **Font Awesome**

## 🔒 Privacy Disclaimer

This website respects your privacy. No personal information is shared. Pet listings are user-generated and accuracy is not guaranteed.
